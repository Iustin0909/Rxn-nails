# Luna Nail Atelier

A responsive, single-page nail salon website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in any modern browser. No installation or build step is needed.

For the best experience, serve the folder with a simple local web server (for example, the **Live Server** extension in VS Code).

## Included

- Responsive layouts for small phones, tablets, desktops, landscape screens, and touch devices
- Accessible 44px minimum tap targets, keyboard focus states, and reduced-motion support
- Service menu and image gallery
- Appointment form with native front-end validation and confirmation state
- Contact details, map-style location placeholder, and validated contact form
- External Unsplash image URLs and Google Fonts

## Note

The booking and contact forms are front-end demonstrations: they validate and show success feedback, but do not send data to a server. Connect the `submit` handlers in `script.js` to your preferred form or booking provider when ready.
